RUN-LENGTH LEFT-CENSORING   (run_length_censored)
=========================================================================================================================
A run is censored when it starts at an artificial point: the loan's first observed row if that row is not its
origination (loan_age > 1 there), or the row after an interior gap. True until the first genuinely observed state
change. Asserted per quarter over every loan's full history (before role assignment): a first row at origination is
unflagged; a later entry is flagged; the flag is constant inside a run and never goes false then true without a
gap; every row after a gap is flagged; every post_gap panel row is flagged; never null.
