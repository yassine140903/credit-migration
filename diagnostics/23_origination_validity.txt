=========================================================================================================================
held = what data/panel stores, read from the parquet. Classes, in this order:
    null        the stored value is null
    sentinel    the stored number equals the raw sentinel (9999 / 999)
    raw value   the stored number equals the raw value, parsed (float32): a value that
                is NOT valid and was passed through unchanged
    other       anything else (a zero, a parse artefact, a derived number)
The VALID rows are the control: every one should be 'raw value'.
